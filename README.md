## Featured Projects
 
🛣️ **[Lane Segmentation & Driver Scoring](https://github.com/HitaishiD/Lane_segmentation_project)** · *personal project*

Classical OpenCV pipeline vs. fine-tuned DeepLabV3+ on KITTI Road (tuned using Optuna), stress-tested on real driving footage in rain, night and snow, then turned into an in-lane/out-of-lane driver score. **Lane IoU 0.87 vs 0.10** for the deep learning model vs the classical baseline, at ~52 FPS. [Blog series ↗](https://hitaishid.github.io/#real-time-driver-scoring-with-lane-segmentation)
 
📊 **[Customer Churn Prediction](https://github.com/HitaishiD/churn_prediction_streamlit)** · *team project*

Churn prediction for a music-streaming service from raw activity logs, packaged as a tested, containerized Streamlit app (pytest, CI, Docker).
 
⚡ **[KNN with MapReduce](https://github.com/chKenza/KNN-MapReduce)** · *team project*

**Distributed K-Nearest Neighbors** on Spark (RDD and DataFrame implementations) on the UCI Poker Hand dataset, following the Maillo et al. MapReduce approach.
 
📈 **[Asset Allocation Performance Forecasting](https://github.com/laikhuramkorouhanba/qrt-long-or-short)** · *team project*

QRT × ENS challenge: A directional classifier of portfolio allocations from 20-day return and volume windows with engineered features and CatBoost. **CV accuracy 0.530**, above the 0.508 benchmark.
 
⚖️ **[ThinkCarefully: COMPAS scoring analysis](https://github.com/MaximeDespreaux/ThinkCarefully)** · *team project*

Logistic regression vs. XGBoost vs. TabPFN on recidivism data, compared on **performance, interpretability, stability and fairness**, with a side-by-side Streamlit app.
